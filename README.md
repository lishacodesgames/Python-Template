# Python Template
This project contains a simple main.py that prints "Hello World!" to act as a starting point for you project.

## Steps to use template
1. `git clone https://github.com/lishacodesgames/Python-Template.git`
2. Run the *setup* script in `scripts/` that corresponds to your platform (`setup.bat` for Windows, `setup.sh` for Mac/Linux)
3. Start coding! :D
4. Run the *run* script in `scripts/` that corresponds to your platofrm (`run.bat` for Windows, `run.sh` for Mac/Linux) to run your python program

## Requirements
- Python 3
- If on Linux, you will also require `python3.12-venv`
